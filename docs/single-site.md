### [自动插件安装](#automatic-plugin-installation)

1. 登录您的 WordPress 后端。
2. 转到 插件 > 添加插件。
3. 您将看到特色插件的 bbPress 部分，您可以从那里安装，或者您可以在搜索栏中键入“bbPress”并按 Enter 键来搜索插件。
4. 单击立即安装。
5. 现在启用 bbPress 插件。

### [手动插件安装](#manual-plugin-installation)

使用 WordPress 的插件上传器

1. 从<https://bbpress.org/download/> 或 <https://wordpress.org/plugins/bbpress/>下载 bbPress 插件 。
2. 转到 插件>添加插件
3. 然后单击顶部的上传插件按钮。
4. 单击“选择文件”，然后选择您下载的 bbPress zip 文件。
5. 点击立即安装，现在启用。

使用FTP

1. 从<https://bbpress.org/download/> 或 <https://wordpress.org/plugins/bbpress/>下载 bbPress 插件 。
2. 下载文件后，解压，将插件文件夹解压到桌面
3. 您可以启动您喜欢的 FTP 客户端，如 [FileZilla](https://filezilla-project.org/)。
4. 在您的计算机上找到并打开包含新插件的文件夹。
5. 将 bbPress 文件夹从您的计算机上传到/wp-content/plugins 。
6. 登录您的 WordPress 网站。
7. 转到 插件 > 已安装插件。
8. 单击 bbPress 插件上的启用。
